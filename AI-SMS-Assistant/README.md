# دستیار هوشمند پیامک

نسخه اولیه اپلیکیشن اندروید برای پاسخ خودکار به پیامک‌های مخاطبین ذخیره‌شده.

## امکانات
- فقط شماره‌های موجود در مخاطبین گوشی پاسخ می‌گیرند.
- شماره‌های ناشناس و کوتاه‌کدها نادیده گرفته می‌شوند.
- به هر مخاطب حداکثر هر ۲۴ ساعت یک پاسخ ارسال می‌شود.
- متن پاسخ شامل امضای «دستیار هوش مصنوعی» است.
- فعال‌سازی پس از اعطای مجوزهای دریافت SMS، ارسال SMS و مخاطبین انجام می‌شود.

## ساخت APK
گردش‌کار GitHub Actions با نام **Build Android APK** پس از push یا اجرای دستی، فایل APK آزمایشی را در بخش Artifacts قرار می‌دهد.

## نکات مهم
این نسخه اولیه برای نصب مستقیم و آزمایش شخصی است و برای انتشار در Google Play آماده‌سازی نشده است. ارسال پیامک ممکن است هزینه اپراتور داشته باشد. قبل از فعال‌سازی دائمی، با چند مخاطب مورداعتماد آزمایش کن.
